# Verity Android — Forge 1.20.1

Original lightweight Verity-inspired companion mod for Forge 1.20.1.

Target: Android launchers such as MJ Launcher. The entity uses a low-frequency update interval and lightweight AI to reduce mobile CPU load.

## Build
Use Java 17 and run `gradlew build` from a ForgeGradle 6 setup. The finished JAR is in `build/libs/`.
